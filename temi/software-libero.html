SOFTWARE LIBERO

Software libero Free Software Logiciel libre

Usare strumenti che non hanno bisogno di venderti per esistere.

Using tools that don't need to sell you to exist.

Utiliser des outils qui n'ont pas besoin de vous vendre pour exister.

Un programma che non puoi ispezionare è una scatola nera a cui hai dato accesso alla tua vita digitale sulla fiducia. Il software libero non è (solo) una questione di prezzo: è la differenza tra usare uno strumento e dipendere da una promessa che nessuno può verificare.

A program you can't inspect is a black box you've given access to your digital life, on trust alone. Free software isn't (just) a matter of price: it's the difference between using a tool and depending on a promise no one can verify.

Un programme que vous ne pouvez pas inspecter est une boîte noire à laquelle vous avez donné accès à votre vie numérique, sur la seule confiance. Le logiciel libre n'est pas (seulement) une question de prix : c'est la différence entre utiliser un outil et dépendre d'une promesse que personne ne peut vérifier.

Non serve saper leggere codice per beneficiare di questo — basta che qualcuno possa farlo, e che lo faccia davvero. È lo stesso motivo per cui ti fidi di più di un contratto che chiunque può leggere che di uno scritto in una lingua che solo l'altra parte capisce.

You don't need to know how to read code to benefit from this — it's enough that someone can, and actually does. It's the same reason you trust a contract anyone can read more than one written in a language only the other party understands.

Il n'est pas nécessaire de savoir lire du code pour en profiter — il suffit que quelqu'un le puisse, et le fasse réellement. C'est la même raison pour laquelle vous faites davantage confiance à un contrat que n'importe qui peut lire qu'à un contrat rédigé dans une langue que seule l'autre partie comprend.
